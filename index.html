    Which site is still standing?

    The same measured ground, put through one hundred different sets of mission requirements. A requirement set is an arrival year drawn from the measured 2026–2040 record plus the four demands the selector already enforces. The site that meets every demand in the most sets wins, which is not always the site with the best single score. Nothing here changes the site you picked or the mission you set: it is a read-only comparison you can leave at any time.
